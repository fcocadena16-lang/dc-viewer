DC Viewer v12.0

Cambios principales:
- Rediseño oscuro estilo iOS con barra inferior: Pruebas, Subestaciones y Ajustes.
- Mantener presionada una prueba activa el modo selección.
- Barra flotante de eliminación sobre la pantalla.
- Deslizar hacia arriba desde la zona inferior vuelve a la pantalla anterior.
- Datos permanentes por subestación para banco de baterías y cargador.
- Configuración de baterías abiertas/selladas y número de celdas.
- Registro único por fecha que puede contener lecturas individuales y prueba de descarga.
- Captura de voltaje, densidad, temperatura y agua por celda; en selladas se ocultan densidad y agua.
- Asociación automática de CSV por nombre de subestación y fecha.
- Separación visual de Recuperación post-descarga.
- Versión y comprobación/instalación de actualizaciones en Ajustes.
- Conserva las pruebas de la base de datos de versiones anteriores mediante migración de IndexedDB.
